## 🌟 عن المشروع (About The Project)

**Wanderly** هي صفحة هبوط تفاعلية لوكالة سفر وحجوزات سياحية تستهدف المسافرين بغرض الترفيه، الأزواج، العائلات، والمجموعات الراغبة في استكشاف وجهات عالمية مميزة.

### **الأهداف الأساسية:**

- **إلهام الزوار:** عرض الوجهات السياحية والباقات بشكل جذاب.
- **تبسيط الحجز:** توفير أداة بحث وحجز عائمة وسريعة الاستخدام.
- **عرض الخيارات:** المقارنة الشفافة بين مستويات التسعير المختلفة.
- **بناء الثقة:** إبراز المزايا التنافسية، الإحصائيات، وآراء العملاء.

## 🎨 الهوية البصرية وشخصية التصميم (Design Identity)

يعتمد التصميم على خلفيات أزرق سماء مشرق مع بطاقات بيضاء ناعمة لإنشاء شعور بالاتساع والحرية والتألق.

- **الشخصية:** متفائل (Optimistic)، مغامر (Adventurous)، موثوق (Trustworthy)، نظيف (Clean)، وراقي بحس بسيط (Slightly Premium).
- **الألوان الرئيسية:**
  - 💙 **Sky Blue (الأزرق السماوي):** اللون القيادي للعلامة التجارية والواجهة الرئيسية.
  - ⚪ **Pure White (الأبيض الصافي):** خلفية البطاقات السطحية والأسطح المرفوعة.
  - 🌑 **Dark Blue (الأزرق الداكن):** للنصوص والعناوين لضمان وضوح القراءة.
  - 🌟 **Warm Accents (ألوان دافئة):** للتقييمات، الإبرازات، والأزرار الثانوية.
- **الخطوط (Typography):** نظام خطوط عصري بدون زوائد (Sans-serif) بعناوين عريضة وقوية (Uppercase)، مع نصوص دعم مدمجة وسهلة القراءة.
- **الحاويات والظلال:** بطاقات بحواف دائرية ناعمة (`rounded-2xl` / `rounded-3xl`) مع ظلال ناعمة خفيفة تعطي إحساس الطبقات العائمة.

## 🚀 الميزات الرئيسية (Key Features)

1. **شريط تنقل مدمج (Navbar):** شفاف خفيف فوق قسم الهيرو مع وصول سريع للرحلات، الوجهات، وعملية تسجيل الدخول.
2. **قسم واجهة ملهِم (Hero Section):** عنوان مشجع مع عناصر بصريات سفر (طائرات ورقية، سحاب، ظلال معالم).
3. **أداة البحث والحجز (Trip Search Widget):** حاوية عائمة تفاعلية تتيح التنقل بين (الطيران، الإقامة، المواصلات، والتجارب) واختيار التواريخ والوجهة.
4. **كتل المزايا والسفر المريح (Benefits):** عرض 4 نقاط قوة رئيسية للخدمة (تخطيط سهل، خيارات مرنة، دعم مستمر، تجارب لا تُنسى).
5. **الباقات الشائعة (Popular Packages):** شبكة لعرض أبرز الرحلات الجاهزة للتركيز على الصور، التقييم، والسعر.
6. **مستويات التسعير (Pricing Tiers):** بطاقات أفقية وعمودية تسمح بالمقارنة بين 4 فئات رحلات (Essential, Comfort, Premium, Signature).
7. **خطوات الحجز (How It Works):** توضيح الآلية بـ 4 خطوات مبسطة ومتسلسلة.
8. **الإحصائيات وآراء العملاء (Stats & Testimonial):** شريط إثبات اجتماعي أزرق يعزز مصداقية الموقع.
9. **الأسئلة الشائعة والدعوة النهائية (FAQ & Final CTA):** إجابات على استفسارات الحجز ودعوة مباشرة لبدء الرحلة.

## 📁 هيكلية المشروع (Project Architecture)

يتبع المشروع معمارية مجلدات قائمة على فصل المسؤوليات (Separation of Concerns) لسهولة الصيانة والتوسع:

```text
wanderly-travel/
├── public/
├── src/
│   ├── assets/             # الصور والوسائط الثابتة (BACKGROUNDS, PACKAGES, LOGO)
│   ├── components/         # المكونات البرمجية
│   │   ├── layout/         # مكونات التخطيط العام (Navbar, Footer)
│   │   ├── sections/       # أقسام الصفحة الرئيسية (Hero, Search, Pricing...)
│   │   └── ui/             # مكونات واجهة المستخدم الصغيرة القابلة لإعادة الاستخدام (Button, Card...)
│   ├── pages/              # صفحات التطبيق (Home, Trips, Destinations, About...)
│   ├── context/            # إدارة الحالة المشتركة (BookingContext.jsx)
│   ├── constants/          # البيانات الثابتة (Trips, Pricing, FAQ, Navigation data)
│   ├── hooks/              # الخطاطيف المخصصة (useLenis, useReducedMotion)
│   ├── animations/         # إعدادات وقواعد تحريك GSAP
│   ├── App.jsx             # شجرة المكونات وتوجيه المسارات
│   ├── main.jsx            # نقطة الانطلاق الرئيسية للتطبيق
│   └── index.css           # ملف التنسيقات العام وتكوين Tailwind
├── package.json
├── vite.config.js
└── README.md
```

## 🎬 نظام الحركة والتفاعل (Motion & Animation System)

تتبع الحركة فلسفة أنيقة ومحسوبة تعزز تجربة المستخدم دون التسبب في ضوضاء بصري:

- **طبيعة الحركة:** خفيفة، هادئة، متفائلة، وسريعة الاستجابة (Low → Medium Intensity).
- **التوقيت الزمني (Timings):**
  - التفاعلات الدقيقة (Micro-interactions): `150ms – 250ms`
  - الانتقالات القياسية: `300ms – 500ms`
  - كشف الأقسام (Section Reveals): `500ms – 700ms`
  - تحريكات الهيرو الرئيسية: `600ms – 900ms`
- **قواعد التحريك:**
  - الاعتماد الرئيسي على الشفافية (`Opacity`) والإزاحة الخفيفة لأعلى (`TranslateY: 15px-30px`).
  - دعم كامل لتفضيلات تفادي الحركة (`prefers-reduced-motion`).
  - يمنع استخدام الحركة الارتدادية العنيفة (Bounce) أو التدوير المعقد للمكونات.

## ⚡ التشغيل والإعداد (Getting Started)

### **المتطلبات الأساسية:**

- [Node.js](https://nodejs.org/) الإصدار 18.0 أو أحدث.
- مدير الحزم `npm` أو `pnpm` أو `yarn`.

### **خطوات التثبيت:**

1. **استنساخ المستودع (Clone Repository):**

   ```bash
   git clone https://github.com/your-username/wanderly-travel.git
   cd wanderly-travel
   ```

2. **تثبيت الاعتماديات (Install Dependencies):**

   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير (Run Development Server):**

   ```bash
   npm run dev
   ```

   افتح المتصفح على العنوان: `http://localhost:5173`

4. **بناء المشروع للإنتاج (Build for Production):**
   ```bash
   npm run build
   ```

## 🎯 مبادئ الجودة والأداء (Quality & Performance Rules)

- **الأولوية الاستجابة (Mobile-First Philosophy):** تصميم جميع المكونات لتعمل بسلاسة على الهواتف واللوحيات دون أي شريط تمرير أفقي غير مرغوب فيه.
- **فصل البيانات:** عدم تعيين مصفوفات البيانات داخل المكونات مباشرة، بل استدعاؤها من مجلد `constants/`.
- **الأداء والتحميل:** تحسين الصور والأصول البصرية لمنع حدوث إزاحة في التخطيط (Layout Shift).
- **المرجع المعتمد:** يظل ملف `ANALYSIS.md` و `BUILD.md` هما المصدر الرئيسي للحقيقة لأي قرارات تصميمية أو برمجة داخل هذا المشروع.
